# 飞羽精灵本地资料库

本功能采用“文档检索 + 模型提取 + 人工确认”，不内置或生成完整鸟类名录。

## 放置资料

把合法取得的 `.pdf`、`.txt` 或 `.md` 文件放入 `data/knowledge/`。运行数据目录已被 Git
忽略，因此个人购买的电子书不会进入版本控制。扫描型 PDF 暂不执行 OCR；应先转换为带文本层
的 PDF 或 UTF-8 文本。

每个资料文件可以附带同名 JSON。例如 `paper.pdf.json`：

```json
{
  "title": "论文或书籍标题",
  "author": "作者",
  "year": 2023,
  "source_url": "https://example.org/article",
  "rights": "CC BY 4.0",
  "notes": "资料用途与版本说明"
}
```

## 使用规则

- 新增物种时输入鸟名，点击“查阅本地资料”。
- 程序只检索原始文档片段，不建立全量物种数据库。
- 模型只能填写片段明确支持的字段，并显示资料标题、片段位置和原文。
- 资料不足、相互冲突或不能确定亚种时保留空值并提示用户。
- 点击“填写到表单”仍不会保存；最终保存前必须由用户核对。

PDF 文本提取依赖 `pypdf`。OCR、语义向量索引和资料管理界面暂不属于第一版。

## 模型与迁移边界

文件解析和检索在本机完成。生成检索候选词和分类建议时，优先使用 API 管理中选定的外部模型，否则使用本地 Ollama。启用外部模型后，研究问题与命中的原文片段、标题和位置会发送给该服务；粘贴原文的独立分类提取仍使用本地 Ollama。建议先预览并确认，再填写表单。

应用的完整资料库 ZIP 只包含数据库与照片、缩略图、录音，不包含 `data/knowledge/`。迁移时应单独复制资料文件及同名 JSON 元数据；恢复观察资料库不会覆盖现有知识资料。
