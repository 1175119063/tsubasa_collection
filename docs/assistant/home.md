# 探索营地（首页）

首页是项目入口和概览页，用来查看当前记录统计、最近记录以及指定的首页封面。

- “打开鸟类调查册”进入个人鸟类图鉴。
- “登记新发现”进入田野记录并打开新观察录入窗口。
- “选择首页封面”可以从已有观察照片中选择首页主视觉。
- “完整备份资料库”会生成包含数据库和媒体文件的备份包。
- 页面下方“API 管理”用于配置高德与天地图 Key，以及选择飞羽精灵使用本地或外部模型。
- 顶部导航可以前往鸟类调查册、田野记录、区域档案、探索地图、远征日志和收集计划。

飞羽精灵的“精灵对话”支持一般知识问答和连续对话。若启用外部模型，开放式对话、田野查询计划与本地资料研究会使用该服务商；查询实际执行和资料文件检索仍在本机进行。本地资料研究会发送命中的原文片段及出处，对话涉及本地记录时会附加相关摘要；粘贴原文的分类提取与专用页面说明接口仍使用本地 Ollama。飞羽精灵不会自动新增鸟种或保存业务资料。

完整备份包含数据库、照片、缩略图和录音；API 密钥配置和本地知识资料不包含在 ZIP 内，需单独迁移。
