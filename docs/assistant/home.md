# 探索营地（首页）

首页是项目入口和概览页，用来查看当前馆藏统计、最近记录以及指定的首页封面。

- “打开鸟类调查册”进入个人鸟类图鉴。
- “登记新发现”进入田野记录并打开新观察录入窗口。
- “选择首页封面”可以从已有观察照片中选择首页主视觉。
- “完整备份资料库”会生成包含数据库和媒体文件的备份包。
- 页面下方“API 管理”用于配置高德地图，以及选择飞羽精灵使用本地或外部对话模型。
- 顶部导航可以前往鸟类调查册、田野记录、区域档案和远征日志。

飞羽精灵的“精灵对话”支持一般知识问答和连续对话。若启用外部模型，对话文本会发送给所配置的服务商；分类提取和田野筛选仍使用本地模型。飞羽精灵不会自动新增鸟种或保存业务资料。
