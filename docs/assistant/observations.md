# 田野记录

田野记录按主要时间展示每一次相遇。一笔观察可以包含一至二十张照片，也可以记录其中出现的多个物种。

## 登记新发现

1. 点击田野记录页或首页的“登记新发现”，进入统一照片整理界面。原单笔录入页面和独立“批量导入照片”按钮已移除。
2. 选择或拖入一张或多张 JPEG/JPG，每张不超过 10 MB。每张照片分别建立一笔观察；同一次相遇需要补充照片时，保存后进入“修改记录”操作。
3. 在左侧选择照片，右侧搜索并选择已有物种，或登记新物种并填写分类资料；继续填写个体、地点和季节。EXIF 时间逐张读取，缺失时手动填写。
4. 如照片中还有其他物种，在“照片中的其他物种”区域搜索添加，再确认照片与物种的关联。
5. 勾选其他照片，可将当前照片的目标物种、地点与坐标、季节应用过去；每张照片的时间、个体信息和备注分别保留。
6. 点击“保存就绪照片”顺序保存所有已填完整的照片。成功项目不会重复提交，明确失败的项目可修改后重试，也可暂停保存。
7. 同一个新物种随第一笔成功观察创建，后续照片复用；保存后可以单独关联远征，原有远征成员保留。

批量草稿只保留在当前窗口，关闭前请完成保存。保存结果不明时会暂停，请到田野记录核实，避免重复提交。

## 查看与修改

- 每月默认展示前五笔记录；超过五笔时，点击月份右侧“共 N 页，点击展开”可查看整月，再次点击可收起。筛选或排序变更后恢复折叠。
- 点击记录卡片打开详情；多张照片可用缩略图或前后按钮浏览。
- 多物种观察可以使用“上一个物种”和“下一个物种”切换。
- 点击“修改记录”可补充照片、修改照片时间与物种关联、选择封面、移除非最后一张照片，也可编辑当前物种的信息、增加其他物种或删除当前物种记录。
- 一笔观察至少保留一个物种，因此只剩一个物种时不能删除该物种记录。
- “永久删除”会删除整笔观察及其照片、录音和所有物种记录。

## 检索

左侧可按年份、月份、调查区域和时间顺序筛选。飞羽精灵的田野记录查询 skill 可以理解精确日期、日期范围、多个物种、同框照片、目科属种、地点和远征等自然语言条件。模型生成参数化只读查询计划，本地程序校验并执行后，页面只展示实际命中的记录。
