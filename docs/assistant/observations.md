# 田野记录

田野记录按拍摄时间展示每一笔观察。一笔观察对应一张照片，但可以记录照片中出现的多个物种。

## 登记新发现

1. 点击“登记新发现”。
2. 搜索并选择已有物种；如果物种尚未入库，可选择新增物种并填写目、科、属、种及亚种资料。
3. 上传不超过 10MB 的 JPEG/JPG 照片。系统会尝试读取 EXIF 拍摄时间。
4. 填写照片类型、个体信息、时间、地点、坐标和备注。
5. 如照片内还有其他物种，在“照片中的其他物种”区域继续添加。
6. 保存后生成一笔观察记录。

## 查看与修改

- 点击记录卡片打开详情。
- 多物种观察可以使用“上一个物种”和“下一个物种”切换。
- 点击“修改记录”可编辑当前物种的信息、增加其他物种或删除当前物种记录。
- 一笔观察至少保留一个物种，因此只剩一个物种时不能删除该物种记录。
- “永久删除”会删除整笔观察及其照片、录音和所有物种记录。

## 检索

左侧可按年份、月份、调查区域和时间顺序筛选。飞羽精灵的田野记录查询 skill 可以理解精确日期、日期范围、多个物种、同框照片、目科属种、地点和远征等自然语言条件。模型生成参数化只读查询计划，本地程序校验并执行后，页面只展示实际命中的记录。
