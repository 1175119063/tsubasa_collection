# 鸟类调查册

鸟类调查册只展示已经通过观察记录确认的物种。可以按名称、目、科和属筛选。

- 点击物种卡片可查看图鉴详情、分类、生态资料、个体档案、行为档案、亚种档案和照片凭证。
- 行为档案汇总田野记录中的标签；“修改图鉴”可以新增、改名、删除标签，并勾选关联多笔观察。两处共用同一套数据，改名影响所有关联记录，删除标签会移除这些记录的标签选择，但不删除记录。
- 个体档案分别展示观察自动汇总和自定义个体标签；“自动档案照片凭证”只调整自动汇总的入口，自定义标签有独立关联。
- “修改图鉴”可以调整物种简介、生态信息、档案标签和照片凭证；分类修改统一从个人分类树进入。
- 修改共享的目、科或属信息时，使用同一分类节点的其他物种也会采用更新后的名称。
- 在个人分类树中选中目、科、属或物种，点击“修改分类”，可分别修改名称或归属；鸟纲固定不编辑。
- 移动物种只更改该物种的归属；移动属或科会带走整个分支。搜索目标时可以查看完整路径，缺少上级分类时可以补建。
- 点击“预览修改影响”查看前后路径、物种名单和观察数量，核对后点击“确认保存分类”。编号、照片、录音及观察内容保留；重名不会自动合并。
- 分类预览后改变输入，或数据已被其他操作修改，需要重新预览。
- 可以从已有观察中选择物种封面，并为物种添加独立 MP3 录音。
- 从照片凭证进入田野记录后执行“永久删除”，才会删除对应观察；若它是该物种最后一笔观察，该物种也不再出现在调查册中。调整档案凭证引用不等于删除原观察。
- 详情顶部左侧完整展示照片，右侧展示名称、首次遭遇入口、分类、保护等级与生态资料；不显示档案完整度。
- 分类树使用固定圆位插画与单张代表照片；通过父子节点、侧栏搜索或回到鸟纲导航，不再显示顶部路径条。

新增物种目前通过“田野记录”的“登记新发现”完成。
