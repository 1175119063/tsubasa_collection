# 区域档案

区域档案用于维护固定调查地点及其坐标、行政区、地点类型、说明和关联观察。

- 新增地点时可以使用地图搜索、点击地图或拖动标记取得经纬度。
- 地图默认使用高德底图（无需 Key）；配置天地图浏览器端 Key 后优先使用天地图，OpenStreetMap 作为最后一层备用，某一层连续失败或超时会自动换下一层。
- 高德底图是 GCJ-02，而地点保存的是 WGS-84：地图上点击或拖动得到的坐标会先换回 WGS-84 再填入表单，图钉也按所在底图的坐标系投影，所以显示位置与保存值是一致的。
- 中文地点搜索和逆地理编码使用后端配置的高德 Web 服务，与底图配置相互独立。
- 地点详情左侧展示区域资料与已经确认的物种。
- 右侧先展示与本区域关联的远征，再展示区域观察记录。
- 区域观察记录最多预览八笔；“查看更多”会前往田野记录并自动筛选当前区域。
- 一个远征可以到访多个地点，其中一个地点为主要地点。

删除地点会解除观察与该地点的关联，不删除观察、物种或媒体。仍有远征引用该地点时禁止删除，需先处理对应远征。
