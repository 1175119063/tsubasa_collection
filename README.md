# 翼·时光记

翼·时光记是一套在 Windows 本机运行的个人鸟类观察资料库，包含观察记录、个人图鉴、地点档案和观鸟行程。数据库、照片、缩略图和录音均保存在项目所在磁盘中。

当前有效产品规则见 [DESIGN.md](DESIGN.md)，历史开发过程见 [DEVLOG.md](DEVLOG.md)。

## 启动

在项目根目录运行：

```powershell
.\start-demo.ps1
```

看到服务启动信息后访问：

```text
http://127.0.0.1:8000
```

同一时间只需启动一个服务进程。如果出现 `Errno 10048`，说明 8000 端口已有一份羽迹正在运行；关闭旧终端中的服务后再启动即可。

也可以直接调用项目环境：

```powershell
& '.\.conda\envs\yuhen\python.exe' -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

## 页面入口

- 首页：`http://127.0.0.1:8000/`
- 观察记录：`http://127.0.0.1:8000/observations`
- 个人图鉴：`http://127.0.0.1:8000/dex`
- 地点浏览：`http://127.0.0.1:8000/locations`
- 观鸟行程：`http://127.0.0.1:8000/trips`
- API 文档：`http://127.0.0.1:8000/docs`

## 当前界面

“探索者自然调查手册”V2 已成为默认界面，五个正式入口分别是探索营地、鸟类调查册、田野记录、区域档案和远征日志。V2 直接使用同一套本地数据库，并已提供完整的数据录入与管理入口：

- 田野记录：新增、修改、预览和永久删除观察；
- 鸟类调查册：修改简介、分类、生态画像、自定义档案，管理封面、观察凭证和独立 MP3 录音；
- 区域档案：新增、修改、上传封面、关联观察和删除区域；
- 远征日志：新增、修改、关联或解除观察、选择封面和删除远征。
- 探索营地：首页背景可搜索并指定任意一笔已有观察记录，也可恢复为自动使用最新记录；页面下方提供“API 管理”。

原有界面保留为故障排查和迁移回退入口：`/legacy`、`/legacy/dex`、`/legacy/observations`、`/legacy/locations`、`/legacy/trips`。`/preview/*` 仍作为兼容别名保留，但日常使用无需再访问。

新增观察只接受一张不超过 10 MB 的 JPEG/JPG 照片，一笔观察最多记录照片中的 10 个物种，并可附加多段 MP3。每个物种可以分别填写个体或群体、性别、生命阶段、亚种和备注。选择照片后会自动尝试读取 EXIF 拍摄时间；没有可用时间时可以手动填写。

## 飞羽精灵

“飞羽精灵”采用接近常见 AI 聊天软件的多轮对话界面，并保留 RPG 探险助手的视觉和语气。默认通过 Ollama 在本机运行 `qwen3.5:2b-q4_K_M`，应用内模型名为 `feiyu-jingling`。当前能力分为两类：

- **精灵对话**：进行一般知识问答、创意讨论、计划梳理和连续对话；涉及本项目功能时会参考内置页面说明；
- **受约束工具**：从用户粘贴的原文提取分类字段，以及把自然语言转换为田野记录筛选条件。

受约束工具具体包括：

- 在新增物种时，从粘贴的原文中提取目、科、属、种、亚种及中拉名称，预览后再填写表单；
- 在田野记录中，把自然语言转换为年份、月份、物种、地点、远征、排序和多物种筛选条件；
- 依据项目内置说明介绍当前页面的功能。

模型不会代替用户保存资料。分类抽取只允许抄录原文明确出现的信息，名称匹配和最终筛选仍由程序代码执行。首次推理需要加载模型，可能比后续请求稍慢。

首页下方的“API 管理”可以将**精灵对话**切换为任意兼容 OpenAI Chat Completions 协议的外部模型，需要填写 HTTPS Base URL（通常以 `/v1` 结尾）、模型名称和 API Key。切换后只有开放式精灵对话发往外部服务；分类字段提取、田野筛选和页面功能说明仍使用本地 Ollama。外部聊天直接接受自然语言结果，不强制模型输出 JSON。问题明显涉及本地资料时，程序只附加回答所需的馆藏总数与命中条目摘要。对话内容和这部分最小摘要会受外部服务商的隐私政策约束。

首次部署或迁移到另一台电脑时，先安装并启动 Ollama，再运行：

```powershell
.\packaging\ollama\setup.ps1
```

模型状态可用 `ollama list` 和 `ollama ps` 检查，详细设置见 [packaging/ollama/README.md](packaging/ollama/README.md)。

## API 管理与地图

首页“API 管理”统一维护高德地图 Web 服务 Key 和飞羽精灵的模型提供方。浏览器不会回显完整 Key，服务端使用 Windows DPAPI 加密后保存到 `data/integrations.dat`；如果当前进程没有可用的用户配置文件，会退回到本机范围保护并继续依赖文件权限。该文件不进入资料库 ZIP 备份，换电脑后应重新填写密钥。

新增地点时，地图底图来自 OpenStreetMap，Leaflet 资源由 CDN 加载；地点中文搜索与逆地理编码由高德 Web 服务完成。这里需要的是高德“Web 服务”类型 Key，不需要 JavaScript API 的安全密钥。

协议、模型路由和安全边界详见 [docs/API-MANAGEMENT.md](docs/API-MANAGEMENT.md)。

## 本地数据与备份

真实数据保存在项目根目录的 `data` 中，包括 SQLite 数据库及所有导入媒体。该目录已被 Git 忽略，不属于源代码。

首页提供“完整备份资料库”功能。备份使用 SQLite 在线快照，并将数据库、照片、缩略图、录音和校验清单打包到程序旁的 `backups` 目录；也可以在完成后从浏览器下载 ZIP。出于密钥安全与机器绑定考虑，`data/integrations.dat` 不会进入备份。恢复功能尚未实现，恢复前请勿直接覆盖正在运行的软件资料。

数据库结构使用 Alembic 管理版本，软件启动时会自动升级已有资料库。检测到待迁移数据库时，程序会先在 `backups` 中生成通过完整性检查的灾前数据库快照；升级软件前仍建议手动创建一份包含媒体的完整备份。

## Windows 发行包

公开仓库只构建不含任何个人记录的空白版。解压后应保留整个目录结构，再双击 `翼·时光记.exe`；不要只复制 EXE 文件。空白版首次启动时会在发行目录中创建独立的空资料库。

打包脚本不会读取项目根目录中的 `data`。数据库、照片、录音、备份、密钥配置与生成的发行包均不进入版本控制。
