翼·时光记 Windows v0.2.0 · 空白版

使用方法：
1. 将压缩包完整解压到本地磁盘，不要直接在压缩包内运行。
2. 双击“翼·时光记.exe”。
3. 程序会自动打开浏览器；如未自动打开，请访问 http://127.0.0.1:8000
4. 使用结束后，回到黑色启动窗口按 Ctrl+C，或直接关闭该窗口。

版本说明：
- 本版本不包含任何预置物种、观察记录、区域、远征、照片或录音。
- 第一次启动时会自动建立一套全新的本地数据库。
- 使用过程中产生的全部资料都保存在本文件夹的 data 目录中。
- 请保留整个文件夹，不要只移动 EXE 文件。
- 软件完全在 Windows 本机运行，不要求安装 Python、Conda 或数据库软件。
- 如果 8000 端口已被其他程序占用，可在命令行使用“翼·时光记.exe --port 8001”启动。
